# TerraSuite

Applications pour architectes et professionnels du bâtiment : planning, estimation (DPGF, CCTP), faisabilité, chantier, contacts et projets, documentation produits, veille des appels d'offres.

Accès en ligne : https://benimb.github.io/terrasuite/ : application unique TerraSuite, installable sur PC, tablette et téléphone. Le projet est au centre (onglets par phase : ESQ, AVP, PRO / DCE, analyse des offres, chantier, OPR, réception, GPA) ; les bibliothèques (produits, prix, CCTP, contacts, veille AO) sont communes à tous les projets.

Toutes les données (projets, estimations, DPGF, CCTP, plannings, études de site, produits, chantiers et photos) sont synchronisées entre les appareils de l'agence (TerraChantier/ts-link.js et sync.js).

Un compte TerraSuite (e-mail, mot de passe) relie les applications au serveur central : bibliothèque de l'agence et base commune anonymisée. Voir TerraChantier/SERVEUR-CENTRAL.md.
